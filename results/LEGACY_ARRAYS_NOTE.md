# Legacy development-benchmark arrays (not used by the manuscript)

`results/sca_*.npy`, `results/model_comparison.csv`, `results/selective_plasticity_ablation.csv` and the
window-detector `.npy` files were produced on 2026-09-06 (branch `person3-adaptation`, identical blobs on `main`)
by the earlier R^2-increment estimator in `src/sca/models/sca_model*.py`, whose `estimate_local_graph` scored
lag 0 (current-time sources). They contain non-zero lag-0 coefficients and lag-0 plasticity values and do not
correspond to the final lag-zero-free estimator described in the manuscript (Sec. IV).

They are retained unchanged for provenance only. Tables 8-9 and Fig. 8 of the manuscript are regenerated by

    python scripts/regenerate_dev_ablation.py          # -> results/dev_ablation_final/{defaults,calibrated_d4_l2}/
    python scripts/make_detector_plasticity_figure.py   # -> figs/detector_plasticity.png

using `src/sca/models/selective_adaptation.py` (via `selective_adaptation_ablation.py`).
