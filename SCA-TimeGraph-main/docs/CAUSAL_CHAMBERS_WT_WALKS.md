# External benchmark protocol: Causal Chambers wind tunnel

## Selected benchmark

Use **Causal Chambers `wt_walks_v1`**, experiment
**`actuators_random_walk_2`**. This is the 10,000-observation wind-tunnel
time-series experiment
used for the causal-discovery time-series case study by Gamella, Peters and
Buhlmann. It is a better primary external benchmark than generic EEG: the
physical system is real, the variables are measured and manipulated, and a
validated reference causal graph is available.

The reference protocol uses 10,000 observations, partial-correlation testing,
and a maximum lag of ten. The completed external artifact compares SCA with
PCMCI+ under the same variable set, lag range, and preprocessing. Native
CD-NOD is separately specified for the seed-matched synthetic dynamic subset;
do not claim an external CD-NOD result until its native run has completed.

## Acquisition and immutable provenance

Run the downloader once from the repository root:

```text
python scripts/download_causal_chambers.py
```

It stores the official files in `Datasets/causal_chambers/wt_walks_v1/` and
writes `manifest.json`. The manifest records the package version, chosen
experiment, columns, row count, timestamp column, and measured sampling
interval. Do not invent a sampling frequency: report the median interval in
this generated manifest, including the time unit given by the dataset metadata.

## Variables and ground truth

The data card generated by the downloader is authoritative for exact column
names and units. The official standard-configuration graph exposed by the
downloaded client has **32 measured nodes and 42 directed edges**. Variables
include actuator settings (fan inputs and hatch position),
load sensors, and pressure measurements (downwind, upwind, ambient, and
intake). Load the official reference graph through the `causalchamber` package
or retain its supplied adjacency file; do not reconstruct it from variable
names.

## Locked preprocessing plan

1. Select `actuators_random_walk_2`; retain its 10,000 chronologically ordered
   observations after removing only rows documented as invalid by the source
   metadata. (The historical paper used version 1; the current public version
   of that file contains only 1,016 rows, so version 2 is selected here to
   retain the pre-registered 10,000-observation protocol.)
2. Use the source timestamp/index; sort stably and reject duplicate or
   non-monotonic time points. Do not shuffle.
3. Exclude administrative fields (experiment identifiers, free-text metadata,
   intervention markers) from the discovery input, but retain them in the
   provenance file.
4. Impute no values silently. Report missingness per selected signal; use only
   complete contiguous stretches, or fit imputation on the training prefix and
   apply it forward only.
5. Split chronologically: 70% train, 15% validation, 15% test. Fit mean and
   standard deviation on the training prefix only; apply them to later data.
6. Use lags 1--10 for SCA and PCMCI+. Remove self-links consistently
   before edge scoring. Score only the observable nodes shared by estimate and
   official graph.
7. Report precision, recall, F1, SHD, runtime, the sampled column list, and
   every exclusion. Label this as **external static-graph validation**; it does
   not replace the synthetic multiple-regime experiment.
